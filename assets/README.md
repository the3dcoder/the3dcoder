# Profile artwork and product media

The studio cover and project frames were drawn for this profile in October 2026.
The two editable SVG covers provide light and dark colorways. Headline lettering
uses outlined Chakra Petch Bold by Cadson Demak, licensed under the SIL Open Font
License 1.1; see `ChakraPetch-OFL.txt`. No font download is needed to view the art.

The project panels show actual first-party app screens, composed onto original
colored frames. They are illustrative product views, not assertions that a
particular build is currently available in a store.

| Panel | Source and handling |
| :-- | :-- |
| Model Scout | The app's synthetic `mesh-studio.png` calibration fixture; cropped to the dialog so local folder paths are outside the image. |
| Rubetris | `erikade-landscape-20260922.png`, also published at https://rubetris.com/img/erikade-landscape-20260922.png. This is a gameplay preview, not a claim that the latest mobile trilogy update has been published. |
| Doodle Bluff | September 25 public landing-page capture from https://doodlebluff.com, using a generated party name and no room or invitation link. |
| Your Whey Fitness | Owner store screenshots of exercises and statistics, with sample workout data. |
| Adventure Cache | Owner store screenshots of clues and badges, with sample trail data and no precise coordinates. |
| 3DCDesign | Owner store screenshots of the home screen and print cost estimate, with sample printer and material data. |

The last four screenshot sets are also used on https://the3dcoder.com; their
original provenance is recorded in the site's `docs/inventory/flagship-media.md`.
Product screenshots and original studio artwork belong to their respective
first-party projects. The font license applies only to the font-derived lettering.
