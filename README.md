### ⚙️ Automation & Workflows

This profile is built to be self-updating. Slots wired and ready:

- 🐍 **Contribution snake** — `Platane/snk` action renders the grid into a dark/light SVG pair on a nightly cron. Drop the output paths into a `<picture>` block below this line.
- 📝 **Latest posts** — `gautamkrishnar/blog-post-workflow` pulls an RSS feed from the3dcoder.com into an auto-managed list between comment markers.
- 📦 **Ship log** — a small Actions job that reads store release feeds and rewrites a "Recently Released" table on version bumps.
- ⏱️ **WakaTime** — `athul/waka-readme` for weekly coding-time breakdown, if you want language hours alongside repo counts.
